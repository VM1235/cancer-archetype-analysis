1. What the SCLC paper showed

Groves et al., Cell Systems 2022 — Figure 1A–C as one argument

Claim (three panels, one story)

  • A: 120 SCLC cell lines form a 5-vertex simplex (Pareto archetypes), not a round blob.
  • B: Those 5 corners = known TF subtypes (A, A2, N, P, Y).
  • C: Human tumors sit in the same cell-line polytope (ComBat-corrected; do not refit PCHA on tumors).

Biology

Trade-offs → data cloud shaped like a polytope. Vertices = pure tasks; interior = mixtures (plasticity bridge).

Method: Hausser et al. Nat Commun 2019 (ParTI / PCHA). Paper PDFs in papers/.

2. Tools & stack

Core method

  • PCA — truncate to first n PCs with ≥50% variance
  • PCHA (py_pcha) — archetypes as convex combinations of samples
  • ParTI conventions — fit in k−1 PCs; delta=0; max-volume multi-start
  • t-ratio permutation — shuffle each PC across samples
  • Hypergeometric + BH — subtype enrichment in distance bins
  • ComBat (R sva) — cell line vs tumor batch

Software / data

  • Python 3.9+, NumPy < 2 (required by py_pcha)
  • Shared engines: repo src/ (pca, archetypes, enrichment, combat, io)
  • DepMap CCLE expression + Model.csv
  • UCSC Xena TCGA HiSeqV2 + clinical
  • Breast PAM50: R genefu
  • Reference MATLAB clone: reference/ (local only)

2b. Shared protocol (A → B → C)

Panel A — how many corners?

  • PCA on cell lines
  • PCHA for k = 3…7 (or 2…15 for ESV)
  • ESV elbow (DimensionFinder)
  • t-ratio p-values; take smallest significant k

Panel B — what are the corners?

  • Independent subtype labels
  • Distance to each vertex → equal-count bins
  • Call match only if enrichment peaks in bin 0 (q<0.1)

Panel C — do tumors live there?

  • Map cell-line archetypes → gene space
  • Merge + ComBat (batch = line vs tumor)
  • Do not refit PCHA on tumors
  • Scatter + variance vs tumor-only PCA

3. SCLC reproduction

Shuffle caveat for the figures shown: Panel A permutation significance in the exported deck was often driven by a 100-shuffle sanity run (run_panel_a_sanity_parti.py), not the paper’s 1000 × 50-init null. Full ParTI run (run_panel_a_parti_full.py, 1000 shuffles) recovers paper t-ratios to 3 decimals (k=5: t≈0.108, p≈0.045 vs paper p≈0.034) — same qualitative call: k=5 significant, k=4 not.

B: 1-to-1 subtype↔vertex peaks. C: tumors occupy the cell-line geometry after ComBat.

4. Analysing BRCA — what changed in tools/codes

Data & preprocessing

  • DepMap invasive breast cell lines (OncoTree), not Minna+CCLE merge
  • 63 lines × 16,500 genes (drop max log2(TPM+1) < 1)
  • Already log2(TPM+1) — no re-log, no Panel A ComBat
  • Tumors: TCGA-BRCA HiSeq, 1,097 primaries

Code / parameter deltas vs SCLC

  • Drivers under Breast Cancer/codes/; engines still src/
  • PCA dim = first n with ≥50% var → 8 PCs (not 12)
  • ParTI PCHA numIter=5 (15/5 inits) — ParTI lowers this for PCHA
  • 500 shuffles (not 1000)
  • Panel B labels = PAM50 (genefu); drop LumA+Normal from enrichment only
  • Panel C colors = IHC ER/HER2, not PAM50
Official path is current codes/ + figures/ — not archive/run1/.

5. Analysing GBM — what changed in tools/codes

Data

  • DepMap OncoTree GB only (not all CNS) → 54 lines with RNA
  • 15,833 genes after low-expression filter
  • TCGA-GBM HiSeq: 154 primary tumors (shared genes 13,677)
  • Clinical Verhaak GeneExp_Subtype for Panel C colors

Code deltas

  • Paper-scale PCHA: numIter=50 → 150/50 inits (unlike breast’s 5)
  • 500 shuffles; k=3…7 fit in parallel
  • 12 PCs (51.4% variance)
  • Panel B labels: marker z-score Classical / MES / PN on CCLE (TCGA-centroid transfer failed — all MES)
  • Neural subtype not used for line labels (Wang 3-type scheme)
Hypothesis under test: same Groves protocol → significant simplex + vertex↔subtype map + tumors inside. All three failed on this GBM matrix.

5d. GBM — forcing k=2 (PN–MES) did not rescue the claim

Hypothesis from Jolly lab / continuum literature: antagonistic Proneural–Mesenchymal axis instead of multi-archetype simplex.

ParTI k=2 in 1 PC → t-ratio ≡ 1 (degenerate)

Relaxation: k=2 in 12 PCs → t≈0.70, p=0.49 (NS)

Still no significant bin-0 subtype peaks

One-sentence status

SCLC Fig 1A–C is a successful Groves reproduction; breast is the same method with mixed/weak significance; GBM (and gene-list / k=2 variants) do not form a significant cell-line simplex, do not put subtypes cleanly at vertices, and do not place tumors inside that simplex — with the protocol and files in this repo.
