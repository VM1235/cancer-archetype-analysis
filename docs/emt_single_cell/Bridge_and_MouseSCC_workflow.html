From the educational report to v2, and the Mouse_SCC workflow

Part A: concepts that bridge the two documents. Part B: everything done in Mouse_SCC/, step by step.

Part A. The bridge

One-line picture. The PDF you read (11 Oct) teaches one dataset (mouse SCC) and one machine: PCA → fit a simplex (PCHA) → test it against shuffled data → name the corners. v2 (17 Oct) keeps that machine, runs it on five datasets, and asks a harder question: is a corner an EMT "task", or just a programme, a batch or a technical axis?

What you already have from the PDF

knownCells as vectors; PCA; convex hull and simplex; barycentric weights; t-ratio; permutation test (p = (1+hits)/(1+shuffles)); ESV elbow for k; versions A / B / C; specialist by gap ≥ 0.35; η² (how much of a PC a label explains).

What v2 adds, in the order you need it

1Two questions, not one

Q1: do corners exist that look like tasks? Q2: do hybrid cells sit at a corner (specialist) or in the interior (generalist)? In the PDF these were mixed together; v2 answers them separately for every dataset.

2Corner = programme, not automatically a "task"

A corner is only a direction of extreme expression. It can be proliferation, matrix/TGF-β response, stress, or technology. This is why v2 stresses naming evidence: marker genes, state mix, tumour mix, and a Hallmark gene-set check (E2F/G2-M → cycling; EMT set → mesenchymal; nothing above +0.25 → technical).

3Confounding is the central problem

In SCC, tumour, assay (scRNA vs multiome) and EMT state are tangled. A pooled fit can pass the permutation test purely because tumours differ. Hence the extra tests: leave-one-tumour-out, scRNA-only (B), six clean tumours, and η² of tumour vs state on each PC. Key lesson: a small p only says "not a shuffled blob", not "Pareto front".

4Pooled fit vs within-sample fit

Pooled: one triangle for all cells (dominated by sample differences). Within-sample: PCA and PCHA done inside one tumour/line/clone, so batch cannot be the explanation. Then cross-projection: freeze one sample's triangle and drop every other sample into it, to see whether the EMT ordering is shared.

5Path versus triangle

If EMT is a single continuum, cells line up on a curve, not a triangle. The path test (script 08c) asks whether a 3-corner shape beats a 1-D path. This is the formal version of "EMT might not have corners at all".

6Specialist rules compared

Gap rule (Pal): top weight − second ≥ 0.35. Closest-5% rule (Groves 2022): the 5% of cells nearest each corner are specialists, the rest generalists. The 98.8% "generalist" number for SCC hybrids uses the second rule.

7Cleaning matters, and can cut both ways

Filters: ≥10,000 UMI, technical genes (Malat1, Neat1, haemoglobin…), contamination panel (4T1). Cleaning created triangles in PDAC and GSE114687 and removed them in 4T1 and Cook. The 17 Oct audit found the technical-gene filter silently did nothing on human data (mouse spelling), fixed it, reran 104 fits; conclusions did not change. Depth (UMI) can itself make a corner, so v2 adds depth regression / matching.

8Replication across datasets

Same pipeline on Cook (cell lines, TGF-β time course), PDAC (metastasis), 4T1 (clones), GSE114687 (MCF10A/HuMEC pseudospace). Only the last shows a triangle inside samples: cycling / differentiated-epithelial / EMT-matrix. That is the "trade-off exists in clean induced EMT, not in tumours" result.

9Honesty log and withdrawn results

Pre-registered predictions (SCC, 4T1 only). Things changed after looking are listed. Notably the SCC regress-out-V1 result (p = 0.04) was withdrawn: it also removed real EMT signal (Krt14, Col1a1 slopes ≈ ±1). Treat anything under that heading as do not cite.
